## Частина В: PHP Service (OOP Refactoring)
Legacy-код було переписано у структурований клас `ReportApp` з дотриманням принципів ООП:
1. Типізація даних і передча їх через конструктор.
2. Фільтрація замовлень лишаючи лише плюсові значення через метод `process()`.
3. Запис методои `write()` , з виконанням умова на блокування файлу під час запису.
4. Логування методом `__destruct()` для автоматичного запису логів у `app.log` по завершенню роботи скрипта.
